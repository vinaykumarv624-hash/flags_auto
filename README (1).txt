FLAGS BATTLE (24/7 stream)  -  with YouTube chat + sound + lofi music

INSTALL
  Windows (Python 3.14):  pip install pygame-ce
  Ubuntu VPS:             pip install pygame
FOLDER LAYOUT (important - keep these together)
  flags_battle.py   music/ (your lofi files)   sfx/ (optional)   flags/ (auto-created)
  If your browser saved it as "flags_battle (1).py", delete the old file and rename it.
  Run:  python flags_battle.py     (or python "flags_battle (1).py")
RUN
  Windows:  python flags_battle.py
  VPS:      DISPLAY=:100 python3 flags_battle.py     (720x1280 Xvfb)
First run downloads ~110 flag images into ./flags (needs internet, ~1 min).

YOUTUBE CHAT (viewers pick the flags)
  Viewers type a country name (india, usa, "south korea") or post a flag emoji.
  Requested flags join the NEXT round (gold ring in the arena), the rest are random.
  After each winner there is a 12-second "TYPE YOUR COUNTRY IN CHAT" screen.
  No chat / no API key / quota used up  ->  plain random game, nothing breaks.
  Setup: nothing new if your falling-pickaxe config.json already has the API key
  and livestream ID (it is read automatically, and re-read every poll so the new
  livestream ID after your 5-hour restart is picked up). Otherwise copy
  chat_config.example.json to chat_config.json and fill it in.
  Quota: each poll = 5 units, free limit = 10,000/day. poll_secs 60 uses ~7,200/day.
  Do not go below ~45 seconds.

BOOST (!boost)
  A viewer types   !boost brazil   (or  !boost + a flag emoji)  and that flag heals
  by BOOST_HP (15) with a green ring, a floating +HP number and a ticker message.
  Limits: 1 boost per viewer per chat poll, 15 boosts per poll, and a flag can't go
  above its max HP. If the country isn't fighting (dead or not in this round), the
  boost becomes a "join the next round" request instead, so nothing is wasted.
  Note: chat is checked every poll_secs (60s), so boosts can arrive up to a minute
  late and then show one after another.

FIGHT SOUNDS (when flags hit each other)
  Built-in punch / slap / heavy-smash sounds. Harder collisions are louder, and the
  biggest hits use the heavy smash. Pile-ups are thinned out so it never turns into
  a buzz. To use REAL fight sounds instead: make a folder named "sfx" next to the
  script and put files named hit1.wav, hit2.mp3, hit3.ogg ... in it (free ones:
  pixabay.com/sound-effects, search "punch" or "hit"). They are picked at random.

SOUND
  Hit / knockout / winner / chat-flag chime / boost blip / countdown ticks are generated by the
  code (no files). Volume: SFX_VOLUME at the top of flags_battle.py.

BACKGROUND MUSIC (volume 5%)
  Put .mp3 / .ogg / .wav files in the "music" folder. They play shuffled and loop
  forever at MUSIC_VOLUME = 0.05 (5%). lofi_placeholder.wav is only a simple
  generated test loop - replace it with real lofi tracks:
   - YouTube Audio Library: YouTube Studio > Audio library > filter "Free to use",
     download the MP3s. Check each track for an attribution requirement (put it in
     your stream description if needed).
   - Or Pixabay Music (pixabay.com/music) - free, no attribution needed.

STREAMING AUDIO FROM THE VPS (important)
  A VPS has no sound card, so ffmpeg cannot hear the game by default. Use a virtual
  PulseAudio device:
    sudo apt install pulseaudio
    pulseaudio --start
    pactl load-module module-null-sink sink_name=stream
    export PULSE_SINK=stream
    DISPLAY=:100 python3 flags_battle.py
  Then add the audio to your existing ffmpeg command (before the output options):
    -f pulse -i stream.monitor -c:a aac -b:a 128k
  (run the game and ffmpeg from the same user session)

SETTINGS (top of flags_battle.py)
  TITLE / SUBTITLE, FLAGS_PER_ROUND, DAMAGE_MIN/MAX, SPEED_MIN/MAX, SHRINK_START,
  CHAT_POLL_SECS, COLLECT_SECS, MUSIC_VOLUME, SFX_VOLUME, COUNTRIES, ALIASES.
Win counts are saved in wins.json. Esc closes the window.
